# VideoTime

โปรแกรม Windows ด้วย C++20 / Qt 6 สำหรับฝังเวลาบนวิดีโอหลายคลิป พร้อม Preview

## เปิดใช้งาน

ดับเบิลคลิก **Launch-VideoTime.cmd** หรือเปิด **dist/VideoTime/VideoTime.exe** เมื่อสร้างชุดโปรแกรมแล้ว

1. เพิ่มไฟล์หลายคลิป หรือเพิ่มโฟลเดอร์ ซึ่งจะค้นหาโฟลเดอร์ย่อยด้วย
2. เลือกคลิปในรายการเพื่อตรวจภาพและแก้เวลาเริ่มต้น
3. เลือกวันเวลานาฬิกาหรือเวลาที่ผ่านไป ปรับฟอนต์ สี ตำแหน่ง และขนาด
4. เลือกใช้เวลารายคลิป หรือต่อเวลาจากคลิปแรกตามลำดับรายการ
5. เลือกส่งออกแยกไฟล์หรือรวมไฟล์ และเลือกโฟลเดอร์ปลายทาง
6. ใช้ “ตัวอย่าง 5 วินาที” เพื่อตรวจผลจริงจากตำแหน่ง Preview ก่อนส่งออกทั้งหมด

เวลาเริ่มต้นอ่านจาก **Date modified ของไฟล์ใน Windows** และถือเป็นเวลาต้นคลิป ไม่ใช่ metadata วันเวลาถ่ายจากกล้อง เก็บวันเวลาท้องถิ่น ณ ตอนนำเข้า รวมถึงค่าที่แก้ไขเองลงโปรเจกต์ เมื่อเปิดโปรเจกต์เดิมจะไม่อ่าน Date modified มาทับค่าเก่า การแสดงผลมีความละเอียดหนึ่งวินาที

แบบต่อเนื่องใช้เวลาเริ่มของคลิปแรกและความยาวของทุกคลิปก่อนหน้า จัดลำดับด้วยปุ่มขึ้น/ลง และแก้เวลาเริ่มที่คลิปแรก รูปแบบข้อความใช้ร่วมกันทั้งชุด ส่วนเวลาเริ่มต้นแก้ได้รายคลิปในโหมดเวลารายคลิป

บันทึกโปรเจกต์ด้วย Ctrl+S เปิดด้วย Ctrl+O; Preset เก็บเฉพาะรูปแบบข้อความ ไฟล์ต้นฉบับจะไม่ถูกเขียนทับ และหากชื่อผลลัพธ์ซ้ำ โปรแกรมจะเพิ่มเลขต่อท้าย

## หน้าจอและตัวเลข

UI ใช้โทนสว่างและฟอนต์ Noto Sans Thai ที่รวมมากับโปรแกรม การตั้งค่าแบ่งเป็นแท็บ “เวลา” และ “รูปแบบ” ส่วนโฟลเดอร์ปลายทางและปุ่มส่งออกอยู่ด้านล่าง เปิด/บันทึกโปรเจกต์และตั้งค่าเครื่องมือได้จากเมนู “โปรเจกต์” มุมขวาบน

วันที่ เวลา เปอร์เซ็นต์ และค่าตัวเลขใช้เลขอารบิก 0–9 พร้อมปี ค.ศ. แม้ Windows ตั้งภาษาไทย รายการเวลาและผลลัพธ์บนวิดีโอใช้รูปแบบเดียวกัน

## ติดตั้งบนเครื่องอื่น

ใช้ไฟล์ **dist/installers/VideoTime-0.1.0-Setup-x64.exe** ส่งไปยังเครื่อง Windows 10 (1809 ขึ้นไป) หรือ Windows 11 แบบ 64 บิต แล้วเปิดเพื่อติดตั้ง ตัวติดตั้งรวม Qt, FFmpeg และฟอนต์ไว้แล้ว เครื่องปลายทางไม่ต้องติดตั้ง Python หรือเครื่องมือพัฒนา และติดตั้งได้โดยไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ

ค่าเริ่มต้นติดตั้งที่ %LOCALAPPDATA%/Programs/VideoTime สร้างทางลัดบน Desktop และ Start Menu ถอนการติดตั้งผ่าน Settings → Apps → VideoTime ได้ ตัวถอนการติดตั้งลบเฉพาะไฟล์โปรแกรมที่อยู่ในรายการติดตั้ง และเก็บวิดีโอ/โปรเจกต์เพิ่มเติมของผู้ใช้ไว้

ตัวติดตั้งยังไม่ได้เซ็นดิจิทัล ค่า SHA256 สำหรับตรวจสอบไฟล์อยู่ข้าง Setup ในไฟล์ .sha256

สร้างตัวติดตั้งใหม่พร้อม build และทดสอบ:

~~~powershell
./tools/windows/build.ps1 -Installer
~~~

หากมีชุด portable ที่สร้างเรียบร้อยแล้ว:

~~~powershell
./tools/windows/installer.ps1
~~~

สคริปต์ดาวน์โหลด NSIS 3.12 ลง .tools และตรวจ SHA256 ของเครื่องมือก่อนใช้ สามารถทดสอบติดตั้ง/ติดตั้งซ้ำ/เปิดโปรแกรม/ถอนการติดตั้งในโฟลเดอร์ใต้ build โดยไม่สร้างทางลัดหรือแก้ registry ด้วย:

~~~powershell
./tools/windows/test-installer.ps1
~~~

## Build บน Windows

ต้องมี Python 3.11 ขึ้นไปสำหรับดาวน์โหลด SDK; ตัวโปรแกรมที่ build แล้วไม่ต้องใช้ Python

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/windows/build.ps1 -Setup -Package
~~~

SDK, คอมไพเลอร์ และเครื่องมือ build จะอยู่ใน .tools ของโครงการ ไม่ติดตั้งทับระบบ ค่าเริ่มต้นคือ Qt 6.8.3 MinGW 64 บิต และ GCC 13.1

หากมี SDK อยู่แล้ว:

~~~powershell
./tools/windows/build.ps1 -QtRoot C:/Qt/6.8.3/mingw_64 -CompilerDirectory C:/Qt/Tools/mingw1310_64/bin -FFmpegDirectory C:/ffmpeg/bin -Package
~~~

FFmpeg ต้องรองรับตัวเข้ารหัส libx264, AAC และฟิลเตอร์ overlay/scale/pad/fps การวาดเวลาใช้ QPainter แล้วส่งภาพ RGBA เข้า FFmpeg จึงไม่ต้องมี drawtext หรือ libass โปรแกรมค้นหา FFmpeg จากการตั้งค่าผู้ใช้ โฟลเดอร์ tools ข้าง executable, PATH และ Shotcut ที่ติดตั้งในตำแหน่งมาตรฐาน หากไม่พบให้ใช้เมนู “โปรเจกต์ → ตั้งค่าเครื่องมือวิดีโอ” เลือก ffmpeg.exe ในโฟลเดอร์เดียวกับ ffprobe.exe

build.ps1 จะรันทดสอบก่อนแพ็กเสมอ ผลลัพธ์พร้อมใช้งานอยู่ที่ dist/VideoTime สามารถย้ายทั้งโฟลเดอร์ได้ ห้ามย้ายเฉพาะ executable

## การตรวจสอบ

ชุดทดสอบตรวจการคำนวณเวลา ข้ามวัน ไม่วนกลับเมื่อเกิน 24 ชั่วโมง เวลาแบบต่อเนื่องที่มีเศษวินาที โปรเจกต์/Preset การอ่านวิดีโอ การส่งออกจริง การรวมคลิปต่างขนาด/FPS/เสียง การสร้างตัวอย่าง การทำงานต่อเมื่อคลิปเสีย และการล้างไฟล์ชั่วคราวเมื่อยกเลิก

หากไม่มี FFmpeg การทดสอบที่ต้องใช้วิดีโอจะรายงาน skipped; การตรวจรับชุดโปรแกรมต้องมี FFmpeg และต้องไม่มี skipped

## รายละเอียดและข้อจำกัด

- ผลลัพธ์เป็น MP4 / H.264 CRF 20 / AAC 192 kbps ประมวลผลด้วย CPU ครั้งละหนึ่งงาน
- การรวมคลิปปรับเป็นขนาดและ FPS ของคลิปแรก รักษาสัดส่วน เติมขอบดำ และเติมเสียงเงียบหากไม่มีเสียง
- รองรับคลิปที่อ่านความยาวได้ ขนาดไม่เกิน 8192 พิกเซลต่อด้าน ความยาวไม่เกิน 7 วันต่อคลิป
- Preview ใช้ Qt Multimedia; บาง codec อาจส่งออกด้วย FFmpeg ได้แต่เล่น Preview ไม่ได้
- ไม่มีการตัดคลิป เอฟเฟกต์เปลี่ยนฉาก หรือ GPU encoding ในรุ่นนี้
- สถาปัตยกรรมและข้อกำหนดการแจกจ่ายไลบรารีอยู่ใน docs/ARCHITECTURE.md และ THIRD-PARTY-NOTICES.md
